# AUD-01c — complément clavier

Préparé le 13 novembre 2026 avant les nouveaux essais.

1. Reproduire la saisie dans une session FlightGear visible et dédiée ; distinguer un problème de fenêtre, de touches automatisées et de liaison du champ.
2. Vérifier deux masses saisies, leur conservation avant Appliquer et leur transmission après Appliquer ; contrôler le total et le CG dans JSBSim.
3. Essayer une valeur négative, du texte et une valeur décimale ; conserver les masses effectives en cas de refus. Vérifier la restauration sans perte de précision.
4. Corriger uniquement les défauts reproduits, garder les recettes du tutoriel synchronisées, puis refaire les tests concernés.
5. Publier des captures natives et les relevés, expliquer la méthode et les limites dans la fiche 11, actualiser les Markdown et le statut ROADMAP.

Achèvement : saisie réellement visible, action Appliquer vérifiée, refus observé, restauration vérifiée. Une écriture directe dans une propriété ne vaut pas une preuve de saisie au clavier.
