# Code de conduite SW233

Ce texte propre au projet s'applique aux Issues, pull requests et autres espaces
communautaires du dépôt. Il ne prétend pas reproduire le Contributor Covenant.

Nous accueillons les personnes de tout niveau et de toute origine. Présenter
les critiques avec des faits, reconnaître les limites de ses connaissances,
respecter les différences et donner crédit aux contributions.

Le harcèlement, les insultes, les discriminations, les menaces et la divulgation
de données personnelles sans consentement ne sont pas acceptés.

Pour signaler un incident, contacter le mainteneur via les moyens publiés sur
son profil GitHub, indiqué dans MAINTAINERS.md. Aucun canal confidentiel dédié
n'est actuellement configuré : ne pas publier de données sensibles dans une
Issue. Un incident non sensible peut être signalé dans une Issue de modération.

Le mainteneur examine les faits, recueille les explications et applique une
réponse proportionnée : rappel, retrait de contenu, restriction temporaire ou
exclusion. Une réévaluation peut être demandée au mainteneur avec des éléments
nouveaux. Les décisions doivent être motivées et respecter la confidentialité.
